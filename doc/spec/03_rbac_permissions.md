# 第三章：角色權限存取控制 (RBAC)

## 3.1 角色定義 (`Role` Enum)
系統定義四大角色，於頂部導航列支援即時切換身份以驗證權限邊界：

| 角色代碼 | 中文名稱 | 職責定位 |
| :--- | :--- | :--- |
| `ADMIN` | 系統管理員 | 管理專案、使用者、全系統權限、欄位增刪修改 |
| `PM` | 專案經理 | 建立專案、分配卡片、建立與審核 RFI、核定官方正式答覆 |
| `MEMBER` | 執行者/工程師 | 更新卡片進度、拖曳狀態、回覆 RFI、上傳附件 |
| `CLIENT` | 客戶/外部人員 | 僅能提出 RFI 與檢視看板，禁止修改內部卡片與拖曳狀態 |

## 3.2 功能權限矩陣

| 操作項目 | ADMIN | PM | MEMBER | CLIENT |
| :--- | :---: | :---: | :---: | :---: |
| 建立與編輯看板卡片 | ✅ | ✅ | ✅ (指派者) | ❌ |
| 跨欄位拖曳卡片 | ✅ | ✅ | ✅ | ❌ |
| 新增 / 刪除看板欄位 | ✅ | ✅ | ❌ | ❌ |
| 提出新 RFI | ✅ | ✅ | ✅ | ✅ |
| 回覆 RFI 留言 | ✅ | ✅ | ✅ | ✅ |
| 核定官方正式答覆 (Official Response) | ✅ | ✅ | ❌ | ❌ |
| 將 RFI 一鍵轉化為卡片 | ✅ | ✅ | ❌ | ❌ |
| 結案 / 駁回 RFI | ✅ | ✅ | ❌ | ❌ |
| 上傳附件 / 貼上螢幕截圖 | ✅ | ✅ | ✅ | ✅ |
