# 第一章：系統概述與專案範圍 (Overview & Scope)

## 1.1 系統定位與目標
「專案管理與 RFI 追蹤系統」是為工程團隊、專案經理 (PM) 與業主客戶 (Client) 設計之敏捷協作平台。
傳統專案常面臨「任務進度看板」與「規格疑問澄清 (RFI)」分散於不同軟體或通訊群組（如 LINE/Slack/Email），導致決策無法回溯、責任不清與資訊斷層。本系統將**看板工作流**、**時程甘特圖**與**官方 RFI 追蹤生命週期**深度整合於單一平台上。

## 1.2 核心展示專案
- **專案代號**：`proj-scm-01`
- **專案名稱**：新一代智慧供應鏈管理平台 (SCM 2.0)
- **專案目標**：整合企業端看板工作流與外部協作 RFI 追蹤系統，強化工程實施與需求釐清效率。

## 1.3 核心特色
1. **雙向關聯機制**：看板卡片可關聯特定 RFI 單號，點擊徽章可直接跨頁跳轉查閱。
2. **RFI 一鍵轉化**：釐清完畢的 RFI 結論，可一鍵轉化為看板實作卡片。
3. **無縫剪貼簿截圖**：支援在任何介面直接以 `Ctrl+V` / `Cmd+V` 上傳截圖。
4. **多層級角色權限 (RBAC)**：嚴格劃分 Admin、PM、Member、Client 職責邊界。
5. **完整審計軌跡**：活動日誌 (Activity Feed) 忠實記錄系統所有關鍵異動。
